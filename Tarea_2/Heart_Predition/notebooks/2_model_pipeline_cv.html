4. Crear el preprocesador (ColumnTransformer)#

from sklearn.compose import ColumnTransformer
from sklearn.preprocessing import MinMaxScaler, OneHotEncoder

preprocessor = ColumnTransformer([
    (
        "numeric",
        MinMaxScaler(),
        numeric_features
    ),
    (
        "categorical",
        OneHotEncoder(handle_unknown="ignore"),
        categorical_features
    )
])

La clave está en que el MinMaxScaler está dentro del Pipeline.Eso evita que el escalado “vea” información del conjunto de prueba.

Las variables numéricas se escalan y las categóricas se convierten a variables binarias mediante One-Hot Encoding.

5. Crear el Pipeline#

from sklearn.pipeline import Pipeline
from sklearn.svm import SVC

pipe = Pipeline([
    ("preprocessor", preprocessor),
    ("svc", SVC(probability=True))

handle_unknown handle_unknown: {'error', 'ignore', 'infrequent_if_exist', 'warn'}, default='error'

Specifies the way unknown categories are handled during :meth:`transform`.

- 'error' : Raise an error if an unknown category is present during transform.
- 'ignore' : When an unknown category is encountered during

will be denoted as None.
- 'infrequent_if_exist' : When an unknown category is encountered

mapped to the category denoted `'infrequent'` if it exists. If the

Specifies the way unknown categories are handled during :meth:`transform`.

- 'error' : Raise an error if an unknown category is present during transform.

Etapa 6: Monitoreo de Deriva de Datos (Data Drift)#

Para asegurar que el modelo de predicción cardíaca se mantenga robusto y preciso cuando se enfrente a nuevos datos en producción, se implementó un análisis de deriva de datos (Data Drift).

La deriva de datos ocurre cuando la distribución estadística de las variables de entrada cambia con el tiempo (por ejemplo, si la población de pacientes cambia de edad promedio o si los hospitales empiezan a reportar la presión arterial de forma diferente), lo que puede degradar el rendimiento del modelo.

Metodología: Se dividió el dataset en un conjunto de referencia (entrenamiento) y un conjunto actual (prueba), ambos con un 80% y 20% de los datos respectivamente. Para visualizar las diferencias en las distribuciones, se generó un histograma comparativo de la variable Age (edad), superponiendo las distribuciones de ambos conjuntos. Este análisis permite identificar si existe una discrepancia significativa entre los datos históricos y los datos nuevos.

Resultados:

  • Se generó un gráfico comparativo (histograma) donde se observan las distribuciones de la variable Age en ambos conjuntos.

  • Los histogramas muestran una alta superposición entre los datos de entrenamiento y los de prueba, lo que indica que no existe una deriva severa en esta variable. Esto sugiere que el modelo se está aplicando a una población con características similares a las de su entrenamiento, lo cual es una señal positiva para su estabilidad en producción.

  • Conclusión: El modelo es estable en cuanto a la distribución de la variable analizada. Sin embargo, para un monitoreo continuo en el tiempo, se recomienda ejecutar este análisis de forma periódica para detectar cambios futuros y evitar una degradación silenciosa del rendimiento.
